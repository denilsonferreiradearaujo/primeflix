# Prime Flix

Prime Flix é uma aplicação web desenvolvida em React para exibir uma lista de filmes vinda de uma Api externa podendo visualizar os TOP 10 filmes, acessar os detalhes do mesmo, incluilo a sua lista de favoritos e ver trailer(link direcionado para youtube). 

## 📌 Funcionalidades

- Exibição de uma lista de filmes em carrossel.
- Botão para acessar detalhes dos filmes.
- Interface moderna e responsiva.
- Integração com API para busca de filmes.
- Notificações com React Toastify.

## 🚀 Tecnologias Utilizadas

- [React](https://react.dev/)
- [React Router DOM](https://reactrouter.com/)
- [Axios](https://axios-http.com/)
- [React Slick](https://react-slick.neostack.com/)
- [Slick Carousel](https://kenwheeler.github.io/slick/)
- [React Toastify](https://fkhadra.github.io/react-toastify/)

## 📦 Instalação

1. Clone este repositório:
   ```sh
   git clone https://github.com/denilsonferreiradearaujo/primeflix
   ```

2. Acesse a pasta do projeto:
   ```sh
   cd primeflix
   ```

3. Instale as dependências:
   ```sh
   npm install
   ```

4. Inicie a aplicação:
   ```sh
   npm start
   ```
